# run_script

A Python 3.14+ library for ordered functions, explicit pauses and resumable JSON
progress. The runtime has no third-party dependencies.

Development scope and acceptance criteria are recorded in the
[roadmap](https://github.com/outside-labs/run_script/issues/1) and
[Project](https://github.com/orgs/outside-labs/projects/12).

Run the unit tests with `uv run python -m unittest discover -s tests -v`.
